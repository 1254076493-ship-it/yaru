# AI 文案生成系统（专属规则版）

## 功能
- 输入关键词，一键生成文案
- 严格遵循规则：
  - 口语化、接地气、短句
  - 80-150 字
  - 固定结构：开头抓眼球 + 核心卖点 + 结尾引导
  - 禁止夸张和虚假广告语
  - 结尾固定落款：`——XX出品`
- 一键复制文案

## 快速运行
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app/main.py
```

打开浏览器访问：`http://127.0.0.1:5000`


## 如何验证是否符合你的预期

### 1) 自动化测试（推荐先跑）
```bash
python3 -m unittest discover -s tests -p 'test_*.py' -v
```
会校验：
- 结尾是否固定为 `——XX出品`
- 主体字数是否在 80-150 字
- 是否包含固定三段结构的关键句
- 接口在正常/空关键词下的返回是否正确

### 2) 手动体验测试（看真实效果）
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app/main.py
```
打开 `http://127.0.0.1:5000`，按下面步骤验证：
1. 输入关键词（如：`护肤 熬夜 补水`），点击“生成文案”。
2. 检查结果是否满足：
   - 开头抓眼球（是否有吸引注意的首句）
   - 中间有核心卖点（是否讲清价值和方法）
   - 结尾有引导（是否引导继续动作）
   - 最后固定 `——XX出品`
   - 整体是否口语化、短句、不浮夸
3. 点击“一键复制”，粘贴到任意文本编辑器确认已复制。

### 3) 回归测试建议
每次你调整“专属规则”后，至少执行一次自动化测试和一次手动体验测试，确保不跑偏。
